# LOOKaL SEO Foundation

## Public search positioning

Primary public language should stay human and local:

- skrin komuniti
- iklan perniagaan tempatan
- iklan skrin digital
- iklan di premis
- pilih lokasi iklan
- pemilik premis
- sertai LOOKaL

Industry terms such as DOOH, node, endpoint, inventory and campaign delivery are not primary landing-page language.

## Canonical site

`https://lookal.tech/`

## Current technical foundation

- unique title and meta description
- canonical URL
- robots meta
- Open Graph metadata
- Twitter metadata
- `Organization` and `WebSite` JSON-LD
- `robots.txt`
- `sitemap.xml`
- semantic heading structure
- descriptive image alt text
- lazy loading for below-the-fold location images
- mobile-first static delivery


## Keyword and entity strategy

LOOKaL does not use a `meta keywords` tag or repeat exact-match phrases unnaturally.

Use search language where it helps people understand the page:

Primary intent:
- iklan skrin komuniti
- iklan skrin digital
- iklan perniagaan tempatan
- iklan di premis
- pilih lokasi iklan
- iklan digital offline
- rangkaian skrin komuniti

Supporting intent:
- cara iklan LOOKaL berfungsi
- harga iklan skrin
- iklan ikut lokasi
- iklan untuk perniagaan tempatan
- upload poster iklan
- iklan video di skrin

Entity clarity:
- LOOKaL
- Uniras Sdn Bhd
- Snap2Ads
- skrin komuniti
- premis sebenar
- tayangan iklan
- lokasi
- kempen

Keywords should appear naturally in title, headings, visible copy, descriptive alt text and links when relevant. Do not create thin pages for every keyword variation.

## AI Engine Optimization / AIEO

AIEO is treated as an extension of good SEO and content architecture, not a separate keyword-stuffing system.

Current foundation:
- important content is visible as HTML text
- concise direct-answer FAQ content
- clear Organization, WebSite and Service entities in JSON-LD
- structured data must match visible page claims
- canonical public URL is explicit
- robots and sitemap are public
- OAI-SearchBot access is explicitly allowed
- claims separate current capabilities from future vision
- real photos and videos support first-hand product evidence

See `docs/AIEO.md` for the operating model.

## Claims discipline

SEO copy must not turn screen plays into audience impressions.

Always distinguish:
- tayangan iklan pada skrin
- jumlah individu yang melihat
- measured facts
- estimates

## Future content architecture

Add only when enough real content exists:

- `/iklan` — how advertising works
- `/lokasi` — active LOOKaL locations
- `/pemilik-premis` — join the network
- location/city pages only when the network has real, useful local coverage

Do not create thin city pages solely for keywords.
