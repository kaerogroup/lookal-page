# LOOKaL Page

Official public website for **LOOKaL — Rangkaian Media Komuniti**.

## Purpose

This repository is the public-facing website source of truth for LOOKaL.

It is intentionally separate from:

- `kaerogroup/lookal-platform` — legacy application work
- `kaerogroup/lookal-snap2ads-creative-engine` — Snap2Ads creative-engine R&D/runtime

## Positioning

**LOOKaL = Rangkaian Media Komuniti**

> Iklan komuniti, dekat dengan pelanggan anda.

LOOKaL places community media screens inside real premises where people eat, shop, transact and wait.

## Current surface

The official landing page lives in `index.html`.

The first release is intentionally static and dependency-free so it is easy to audit, deploy and iterate.

## Claims discipline

Public copy must distinguish:

- screen plays / tayangan from people/viewers
- measured facts from estimates
- network-wide facts from location-specific facts

Do not publish unsupported audience-attention percentages or guaranteed publisher returns.
